# Дед Захар

Визуальная новелла на движке RenPy.

## Описание

Интерактивная история с элементами квеста. Проект выполнен в рамках дисциплины "Операционные системы".

## Структура

- `game/script.rpy` — основной сценарий
- `game/options.rpy` — настройки
- `game/minigames/` — мини-игры

## Запуск

Открыть через RenPy SDK
